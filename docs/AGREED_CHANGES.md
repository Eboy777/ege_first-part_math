# Актуальные согласованные правила

Этот документ фиксирует уточнения пользователя после исходного ТЗ и имеет приоритет при расхождениях. Разработаны этапы 1–7.

- ЕГЭ-2026, первая часть из 12 заданий, 56 типов. Дизайн А на имеющейся дизайн-системе.
- Цикл типа: 3 обучающих + 2 контрольных задачи из проверенного банка. Основные ответы проверяет точный серверный модуль, не ИИ.
- Неверный ответ в контроле оставляет ту же задачу для самостоятельного исправления и не открывает чат автоматически.
- Математическая помощь ИИ или просмотр теории/примера снимают самостоятельность текущей контрольной попытки. Для зачёта требуется новая задача того же шага. Уже завершённые шаги сохраняются.
- В обучении после неверного ответа открывается основной чат с просьбой объяснить решение. Ошибка сохраняется только после объяснения и допустимого диагноза с доказательством из слов ученика.
- Основной чат один на ученика; автоматически передаются последние 10 сообщений, включая новое. Старый текст добавляется только явной цитатой. Основной чат не получает профиль ошибок.
- Кнопка «Спросить ИИ» появляется над выделением текста. Прикрепление фото и отправка находятся внутри поля ввода. Техническая кнопка «Как вводить ответ?» удалена из интерфейса.
- Свои задачи и фото не меняют прогресс и файл ошибок. Фото сначала распознаётся, затем требует подтверждения конкретной версии до помощи.
- Повторение 7 дней отсчитывается от освоения типа. Срок 30 дней назначается только после завершения повторения 7 дней и равен этой дате + 30 суток. Срок 90 дней остаётся от даты освоения.
- Очередь повторений 7 → 30 → 90, без автоматического зачёта просроченных точек. Каждое — 2 новые самостоятельные задачи. Основные 5/5 сохраняются.
- Уведомления добровольные, стандартный Web Push. Для iPhone приложение добавляется на главный экран; требуется HTTPS и разрешение ученика. Нет почты, Telegram и платных сервисов.
- Отработка — отдельный сохраняемый чат. До пяти личных ошибок: tasks_solved по возрастанию, затем дата выявления, затем устойчивый ключ.
- По выбранной ошибке ИИ генерирует пример либо контрольный вопрос и сам перепроверяет в том же запросе. Применяются готовые промпты. Скрытый эталон хранится на сервере.
- Завершённый пример или вопрос даёт +1 один раз по UUID. Подсказки и неверные ответы не увеличивают счётчик. После завершения пять вариантов пересчитываются. Обычное обучение и повторения не меняются.
- AI-провайдер: Aijuju, gpt-6.1-sol. Ключ только на сервере. Предыдущая интеграция ModuleAPI заменена.
- Надпись «Демонстрационный прогресс» убрана из интерфейса по просьбе пользователя. В БД тестовое происхождение сохраняется.

Методики: 12 файлов из [EduAI / bot/methods_v2](https://github.com/AL1an-69/EduAI/tree/e0a9011c8c9b76e83f7c5ac6c687eb963c4a5ad2/bot/methods_v2), явная карта к 56 типам в trainer/learning/data/method_map_2026.json. Используются вместе с теорией и алгоритмом конкретного типа.

Тестовые ошибки, прогресс и пароли конкретной установки не входят в репозиторий. Команды demo_reviews и demo_mistakes создают новые тестовые данные только по явному вызову.
