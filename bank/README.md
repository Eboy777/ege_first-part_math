# Рабочий банк задач

approved_tasks.json — экспорт 923 опубликованных задач ЕГЭ-2026 с проверенным ответом и одобренным статусом источника. Здесь только контент, без пользователей, попыток, сообщений и прогресса.

Сначала выполнить seed_catalog_2026 --catalog-only, затем import_bank bank/approved_tasks.json. Нужные изображения сохранены в assets/tasks. Источники, условия использования, проверочные ответы и отметки проверки находятся в каждой записи.

Импорт атомарный и не перезаписывает существующие задачи. Повторный импорт тех же ID намеренно отклоняется. Исследовательские выгрузки, неподтверждённые кандидаты, скачанные страницы и промежуточные отчёты сюда не входят.
