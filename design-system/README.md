# Дизайн-система «Пятёрка»

Источник: https://5-rka.ru/, главная страница, 30 октября 2026 года. Это библиотека для разработки новой страницы сайта. Публикация и изменения на исходном сайте не выполнялись.

## Начало работы

Откройте `index.html` — визуальную библиотеку с примерами. Для новой страницы скопируйте `template.html` и замените содержимое. Подключение:

```html
<link rel="stylesheet" href="design-system.css">
```

Сохраните рядом `fonts.css`, `tokens.css`, `components.css`, `extensions.css` и папку `assets`. Сборка и сторонние зависимости не нужны. Для предпросмотра можно запустить `python3 -m http.server 8000` в этой папке. Открытие файлов напрямую тоже поддерживается; копирование в буфер может требовать localhost.

## Что взято из оригинала

`source/original.css` — полный снимок CSS из тегов style главной. В `components.css` отобраны оригинальные объявления: базовые стили страницы, nav, brand, hero, badge, кнопки, block, section, sec-head, step, pricing/plan, final, FAQ и основные адаптивные правила. Снимок не содержит скриптов или сторонних инструкций страницы.

Шрифты Inter 400/500/600/700/800/900 и Caveat 400/600/700 сохранены локально из Google Fonts. Они содержат кириллицу. Используйте Inter для интерфейса, Caveat 700 для коротких рукописных пометок. Не используйте Caveat для длинных текстов и элементов управления. Источники файлов указаны ниже; шрифты распространяются по SIL Open Font License, полный текст в `assets/fonts/OFL-Inter.txt` и `assets/fonts/OFL-Caveat.txt`.

Палитра: кремовый `--bg: #fff5dc`, чёрный `--fg: #1a1a1a`, розовый `--c1: #ff5c8a`, жёлтый `--c2: #ffcb47`, голубой `--c3: #5cd4ff`, лайм `--c4: #b8ff5c`, фиолетовый `--c5: #6c4cff`, оранжевый `--c6: #ff7e3a`, синий `--c7: #2a6fdb`. План-конспект использует `#d9c2ff`, поверхности — белый. Токены экспортированы в `tokens.css` и `tokens.json`.

На главной оригинальные переменные объявлены на body. При намеренной смене темы переопределяйте их на body или вложенном контейнере; одного изменения :root недостаточно. По умолчанию оставляйте значения оригинала.

## Размеры и адаптивность

Контейнер 1320 px, поля 40 px. На ширине ≤980 px поля 24 px, на ≤520 px — 20 px. Основные колонки шагов и тарифов становятся одной колонкой при ≤980 px. H1: 96/56/38 px, вес 900, line-height .95, tracking -.04em; H2: 64/42/32 px, вес 900, line-height .96, tracking -.035em. Лид: 19 px / 1.5 / 500. Обычный текст шага: 15 px / 1.5 / 500.

Оригинальная обёртка `.blocks-wrap` скрывается на телефоне; не помещайте туда обязательное содержимое новой страницы. На телефоне также скрывается `.hero-cta .btn-ghost`: главное действие задавайте через `.btn-primary`. В библиотеке образцы используют отдельную сетку, чтобы все материалы можно было просмотреть с телефона.

Обводка 2 px solid #1a1a1a; финальный CTA — 3 px. Радиусы: карточка 16 px, шаг 18 px, тариф 22 px, CTA 24 px, кнопки 999 px. Тени без размытия: метка 3 px, карточка 4 px, шаг/тариф 6 px, CTA 8 px. Primary hover сдвигается (2,2) px с тенью 3 px; ghost — (-2,-2) px с тенью 4 px. Анимации 150–200 ms.

## Что добавлено

`extensions.css` содержит новые поля `.field`, ошибку `.field-error`, disabled, focus-visible и reduced-motion. Эти элементы не извлечены с главной: они разработаны для будущих страниц на основе её визуального языка. Ошибки обозначайте текстом и `aria-invalid="true"`, связывайте пояснение через `aria-describedby`. Переходы оформляйте ссылками, действия — кнопками.

Оригинальные сочетания розового с белым и голубого с белым подходят не для любого размера текста. Для мелких подписей и управляющих элементов используйте чёрный текст на светлом фоне; у ошибки задан отдельный тёмный цвет. Сохранение исходного CSS не означает, что весь исходный сайт соответствует WCAG.

`showcase.css` и `showcase.js` оформляют только библиотеку; новой странице они не нужны. Масштабирование типографических образцов в библиотеке отличается от реального H1/H2 — точные размеры сохранены в компонентах и шаблоне.
