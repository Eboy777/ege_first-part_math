# Промпты ИИ

core.md и файлы ролей задают контракт основного чата, распознавания фото, диагностики и отдельной отработки. promptkit.py собирает запрос с окном 10 сообщений и проверяет структуру ответа. Начисления и изменения состояния выполняются только сервером learning.

Провайдер настроен в learning/ai_provider.py: Aijuju, gpt-6.1-sol. Секрет берётся из AIJUJU_API_KEY либо приватной .runtime/aijuju.key. Основной чат не получает профиль ошибок. Генерация отработки включает самопроверку в том же запросе.

Актуальные правила: ../../docs/AGREED_CHANGES.md. Проверки: `python -m unittest discover -s tests` из этой папки. Исследовательские и живые отладочные отчёты в репозиторий не включены.
